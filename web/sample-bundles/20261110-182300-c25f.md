## 1. benchrun.py (runner, stdlib only)
`python3 benchrun.py run <run_dir>` reads <run_dir>/spec.json: {id, label, notes, tasks: [...], samples, max_tokens, url}. It:
- Writes <run_dir>/env.json once at the start, a snapshot of the setup: date, hostname, the server's model id and n_ctx (from GET /v1/models: data[0].id and data[0].meta.n_ctx), the path, sha256 and a flattened copy of the Basalt config (BASALT_CONFIG env, default ~/basalt_config.json; read only, never written; flatten to "models.0.max-context": 262144 style keys), and the Basalt git commit (`git -C ~/basalt rev-parse --short HEAD`, BASALT_DIR env; "" if that fails).
- Does a warm-up `chat(url, model, "Reply with OK.", 64)` that is not counted, as the existing scripts do.
- Runs samples in ROUND-ROBIN order: sample 1 of every task, then sample 2 of every task, and so on. Slow drift over hours (heat, the engine's adaptive expert placement) then hits all tasks equally, and a stopped run still has balanced data.
- Appends each graded sample immediately as one JSON line to <run_dir>/samples.jsonl: {task, sample, seed, passed, total, score (passed/total, 0 if total is 0), plus the chat metrics, error, tail (last 300 chars), t (unix time)}. Save the answer text to <run_dir>/answers/<task>_s<n>.md.
- RESUMES: (task, sample) pairs already in samples.jsonl are skipped, so a stopped or interrupted run can be continued.
- Writes <run_dir>/progress.json after every sample: {done, total, current: "h2_cron sample 3", eta_s} (ETA from the mean seconds per answer so far for each task, or the overall mean for tasks not yet seen).
- Exits 0 when complete. On SIGTERM it finishes nothing more, keeps what is saved, and exits 143. If the server is down at start it exits 2 with a clear message on stderr.
- Every answer runs model-written code through lb.run_tests exactly as the existing bench does (on the host, temp dir, timeout). Do not change that.

## 2. benchstats.py (pure functions, stdlib only)
- `summarize(samples) -> {task: {n, mean, sd, min, max, scores: [...], decode_tps_mean, secs_mean}, "overall": {...}}`, where scores are 0-100 points. The overall score is the mean of the task means (each task weighted equally). Overall spread: sd of the per-sample-index overall score is not meaningful when samples are partial, so report the bootstrap sd of the overall mean (see below).
- `compare(a_samples, b_samples, n_boot=4000, seed=0)` over the tasks both runs have: per task and overall, A mean, B mean, diff (B-A, in points) and a 95% range for the diff by stratified bootstrap. For each resample, resample each task's samples with replacement, separately for A and B, and recompute the per-task means and the overall mean of task means. Use random.Random(seed) so the same inputs always give the same verdict.
- Verdict for each row: "better" if the 95% range is entirely above 0, "worse" if entirely below 0, else "no real difference". If any compared task has fewer than 3 samples in either run, the overall verdict is "not enough samples" (still show the numbers).
- Speed rows (not part of the verdict): decode tokens/s and seconds per answer, with % change and the same bootstrap verdict wording (here "faster/slower/no real difference").
- `env_diff(env_a, env_b)`: the config keys, model id, n_ctx and Basalt commit that differ, as a list of (key, a, b). The page shows "What changed between the runs".

+#!/usr/bin/env python3
+"""benchrun: run one automatic bench run against the local model server.
+
+  python3 benchrun.py run <run_dir>
+
+<run_dir>/spec.json holds everything: {"id","label","notes","tasks":[ids],
+"samples":N,"max_tokens":M,"url":"http://host:port/v1"}. The run writes:
+
+  env.json         snapshot of the setup, once at the start: date, hostname, the
+                   server's model id and n_ctx (GET /v1/models: data[0].id and
+                   data[0].meta.n_ctx), the Basalt config path, its sha256 and a
+                   flattened copy of it (BASALT_CONFIG, default ~/basalt_config.json
+                   - read only, never written), and the Basalt git commit
+                   (BASALT_DIR, default ~/basalt; "" when that fails).
+  samples.jsonl    one JSON line per graded sample, appended IMMEDIATELY, so a
+                   stopped or interrupted run can be resumed: pairs already in
+                   the file are skipped.
+  answers/         the full answer text of every sample as <task>_s<n>.md.
+  progress.json    {done, total, current, eta_s} after every sample.
+
+Samples run ROUND-ROBIN: sample 1 of every task, then sample 2, and so on, so
+slow drift over hours (heat, adaptive expert placement) hits every task equally
+and a stopped run still has balanced data. seed = sample number for every task,
+so a before-run and an after-run get the same seeds (the agent task's seed is
+not settable).
+
+Grading is NOT reimplemented here: it goes through the existing bench code,
+imported as modules from BENCH_DIR (default ~/bench; tests use bench-ref):
+llm_bench (chat, code/bugfix tasks, longctx, agent, run_tests) and hard_ab
+(hard task grading). Model-written code is executed by llm_bench.run_tests
+exactly as the existing bench does (on the host, temp dir, timeout).

+def flatten(obj, pre=None):
+    """{"models":[{"max-context":262144}]} -> {"models.0.max-context": 262144}."""
+    out = {}
+    if isinstance(obj, dict):
+        for k, v in obj.items():
+            out.update(flatten(v, f"{pre}.{k}" if pre is not None else str(k)))
+    elif isinstance(obj, list):
+        for i, v in enumerate(obj):
+            out.update(flatten(v, f"{pre}.{i}" if pre is not None else str(i)))
+    else:
+        out[pre if pre is not None else "value"] = obj

+def env_snapshot(url):
+    """Snapshot the setup. Exits 2 with a clear stderr message when the server
+    does not answer - a bench run is worthless without knowing what it measured."""
+    try:

+            d = json.load(r)["data"][0]
+        model = d.get("id") or ""
+        n_ctx = (d.get("meta") or {}).get("n_ctx")

+                         f"({type(ex).__name__}: {ex}). Start Basalt and try again.\n")
+        sys.exit(2)
