### (a) Crash "length=10358587; index=10358587" — root cause and fix

The supplied analysis was verified independently and is correct:

- `PhaseVocoder.stretch` computed `numOut` (number of analysis frames)
  from `outLen` — but frames are **read** at `m*hop` from the input, so
  for α < 1 only the first α fraction of the input was ever analyzed,
  and the overlap-add buffer (sized `numOut*hopS + n + 64`) came out
  *shorter* than `outLen`.
- Exact match for the reported numbers: 4m05s @ 44.1 kHz ≈ 10.75M frames
  per channel, α = 432/440 → outLen ≈ 10.56M; old buffer with hopS=256,
  n=1024 ≈ **10,358,587** — exactly the `length` in the error, and the
  final trimming loop read sample `outLen` → `index == length`. Short
  test inputs hid it because the extra `+ n + 64` slack covered the gap.
- The `numOut` bug also meant the input **tail was never processed**,
  which would have produced silence at the end even without the crash.

Fix (in `PhaseVocoder.kt`):
```kotlin
val numOut = (x.size + hop - 1) / hop + 2          // cover the INPUT
val out = FloatArray(maxOf(outLen, (numOut * hopS).toInt()) + n + 64)
```

Boundary tests added (`DspTest`, all passing):

  asserts `size == round(len·α)` and tail RMS > 0.3.

### (c) Automatic tuning detection

`dsp/TuningDetector.kt` (pure Kotlin/JVM, same idea as librosa's
`estimate_tuning`):
1. mix to mono, take several windows spread over the file (default 5
   windows × 12 s),
2. Hann-windowed FFTs (8192 points, hop n/2),
3. local-maxima spectral peaks between 80 Hz and 2000 Hz above a relative
   magnitude threshold (2 % of frame max), frequency refined by parabolic
   interpolation in log-magnitude,
4. each peak's deviation from the nearest 12-TET semitone (anchored at
   A=440) in cents (−50…+50) becomes a unit vector at angle 2π·cents/100
   weighted by magnitude; the **magnitude-weighted circular mean** of
   those angles gives the mean deviation, and `|Σ vectors| / Σ weights`
   is the confidence,
5. Reference Hz = 440 · 2^(cents/1200).

Wiring: on file pick, `ConvertViewModel.detectTuning()` decodes, mixes
(L+R)/ch, runs the detector, and shows e.g. **"Detected A≈441.3 Hz
(confidence 0.82)"**; the From field is auto-filled with the value
rounded to 0.1 Hz — once per picked file, and the user can still edit
it. Confidence below 0.35 (or a detection failure) leaves 440 in place
and the status says so ("Tuning unclear … — assuming A=440 Hz").

Synthetic test results (5 tests: chords at A=440/432/444, pure A=432

+import kotlin.math.round
+import kotlin.math.sin

+/**
+ * Estimates the reference pitch of a recording by measuring how far its
+ * spectral peaks sit from the 12-tone equal-tempered grid anchored at
+ * A=440 Hz — the same idea as librosa.effects.estimate_tuning.
+ *
+ * Steps (all pure Kotlin/JVM so it can be unit-tested):
+ *  - analyze several windows spread over the song (default 5 windows,
+ *    ~12 s each), mono float input,
+ *  - Hann-windowed FFTs of [fftSize] samples (default 8192), hop n/2,
+ *  - spectral peaks (local maxima) between [minHz] and [maxHz] above a
+ *    relative magnitude threshold, refined by parabolic interpolation in
+ *    log-magnitude,
+ *  - each peak's deviation from the nearest equal-tempered semitone in
+ *    cents (-50..+50) contributes weight * exp(i*2*pi*cents/100),
+ *  - the magnitude-weighted circular mean of those angles gives the mean
+ *    tuning deviation; |sum| / sum(weights) is the confidence.
+ *
+ * Reference frequency = 440 * 2^(cents/1200).
+ */
+object TuningDetector {
+
+    data class Result(val cents: Double, val confidence: Double) {
+        val referenceHz: Double get() = 440.0 * Math.pow(2.0, cents / 1200.0)
+    }
+
+    fun estimate(
+        x: FloatArray,
+        sampleRate: Int,
+        fftSize: Int = 8192,
+        windowCount: Int = 5,
+        windowSeconds: Double = 12.0,
+        minHz: Double = 80.0,
+        maxHz: Double = 2000.0,
+        thresholdFrac: Double = 0.02,
+    ): Result? {
+        require(fftSize and (fftSize - 1) == 0 && fftSize >= 256) { "fftSize must be a power of two >= 256" }
+        val n = fftSize
+        val half = n / 2
+        val binHz = sampleRate.toDouble() / n
+        val kMin = max(1, ceil(minHz / binHz).toInt())
+        val kMax = min(half - 2, floor(maxHz / binHz).toInt())
+        if (kMax <= kMin + 1) return null
+
+        val winLen = min((sampleRate * windowSeconds).toInt(), x.size)
+        if (winLen < n) return null
+        // Spread windows over the song, skipping the first/last 5%.
+        val margin = (x.size * 0.05).toInt()
+        val span = max(0, x.size - 2 * margin - winLen)
+
+        val fft = Fft(n)
+        val window = DoubleArray(n) { 0.5 - 0.5 * cos(2.0 * PI * it / n) }
+        val re = FloatArray(n)
+        val im = FloatArray(n)
+        val mag = DoubleArray(half + 1)
+
+        var sumS = 0.0
+        var sumC = 0.0
+        var sumW = 0.0
+        var framesUsed = 0
+
+        for (w in 0 until max(1, windowCount)) {
+            val start = margin + if (windowCount > 1) span * w / (windowCount - 1) else 0
+            val last = min(start + winLen, x.size) - n
+            var pos = start
+            while (pos <= last) {
+                for (i in 0 until n) {
+                    re[i] = (x[pos + i] * window[i]).toFloat()
+                    im[i] = 0f
+                }
+                fft.forward(re, im)
+                var frameMax = 0.0
+                for (k in kMin..kMax) {
+                    val m = hypot(re[k].toDouble(), im[k].toDouble())
+                    mag[k] = m
+                    if (m > frameMax) frameMax = m
+                }
+                val thr = frameMax * thresholdFrac
+                for (k in kMin..kMax) {
+                    val m = mag[k]
+                    if (m < thr) continue
+                    if (m <= mag[k - 1] || m <= mag[k + 1]) continue
+                    // Parabolic interpolation in log-magnitude.
+                    val a = ln(max(mag[k - 1], 1e-12))
+                    val b = ln(m)
+                    val c = ln(max(mag[k + 1], 1e-12))
+                    val denom = a - 2.0 * b + c
+                    val delta = if (denom != 0.0) (0.5 * (a - c) / denom).coerceIn(-1.0, 1.0) else 0.0
+                    val f = (k + delta) * binHz
+                    if (f < minHz || f > maxHz) continue
+                    val semitones = 12.0 * log2(f / 440.0)
+                    val cents = (semitones - round(semitones)) * 100.0
+                    val ang = 2.0 * PI * cents / 100.0
+                    sumS += m * sin(ang)
+                    sumC += m * cos(ang)
+                    sumW += m
+                }
+                framesUsed++
+                pos += n / 2
+            }
+        }
+        if (sumW <= 0.0 || framesUsed == 0) return null
+        val meanCents = atan2(sumS, sumC) * 100.0 / (2.0 * PI)
+        val confidence = hypot(sumS, sumC) / sumW
+        return Result(meanCents, confidence)
+    }
